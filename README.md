# LLM Security Write-ups

Personal retrospectives and case studies from adversarial LLM testing and security competitions.

## Write-ups

- [Gray Swan Arena - IPI August 2026](./ipi-august-2026/README.md) - first LLM security competition; indirect prompt injection; **83 / 824** on the leaderboard; reconstructed from preserved Arena traces.

## Disclosure approach

These write-ups focus on methodology, observed failure modes, lessons learned, and defensive implications.
Raw competition exports are kept private by default and are not committed to this repository.
Selected case details are published conservatively; raw exports and full transcript dumps remain private.

## About this repository

This is a learning-oriented portfolio rather than a claim of exhaustive security research.
Where a conclusion is retrospective or uncertain, the write-up says so explicitly.
